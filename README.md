
# 💰 Expense Tracker

A simple, responsive expense tracking web application built with HTML, CSS, and JavaScript. It helps users record expenses, organize transactions, and monitor their spending through a clear dashboard.

## ✨ Features

- ➕ Add new expense records
- ✏️ Edit existing transactions
- 🗑️ Delete transactions
- 📊 View total expenses and spending summaries
- 📈 Visualize expenses with charts
- 🔍 Search and filter transactions
- 🗂️ Filter by category and date
- 📥 Export expense data to CSV
- 💾 Save data in browser Local Storage
- 📱 Responsive layout for desktop and mobile

## 🛠️ Technologies Used

- **HTML5** — Application structure
- **CSS3** — Styling and responsive design
- **JavaScript** — Application logic and interactions
- **Local Storage** — Persist data in the browser
- **Chart.js** — Charts and data visualization, if included in the project

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Add expenses and explore the available features.

For local development, you can also use the Live Server extension in Visual Studio Code.
